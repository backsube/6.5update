# NOUMENON Version 6.5 개발 현황

기준일: 2026-09-01  
기준 브랜치: `Version-6.5`  
원본 계보: `park` 브랜치의 Unity 프로젝트를 Unity 6로 마이그레이션

## 1. 현재 단계

현재는 **플레이 가능한 프로토타입 / Vertical Slice 기반 구축 단계**다. 핵심 탐색·전투·루팅·인벤토리 흐름은 코드와 주 씬에 존재하지만, 정식 게임 루프와 콘텐츠 밸런스, 최종 아트, 맵 완성, 빌드 QA는 아직 진행 중이다.

주 작업 씬 `Assets/Scenes/parkseongbin.unity`에는 약 542개의 GameObject가 있으며, 원본 씬의 지형·오브젝트·적·게임플레이 구성을 Unity 6 프로젝트로 옮긴 상태다.

## 2. 완료 또는 동작 확인된 범위

### 프로젝트 마이그레이션

- Unity `6000.5.10f1` 프로젝트로 전환
- URP `17.5.0`, Input System `1.20.0`, AI Navigation `2.0.14` 구성
- 구형 프로젝트의 스크립트와 핵심 에셋/씬을 대상 프로젝트에 이관
- C# 프로젝트 빌드 기준 경고 0개, 오류 0개 확인

### 플레이어와 전투

- `WASD` 이동 및 마우스 방향 회전
- 우클릭 조준, 좌클릭 반자동 사격, `R` 재장전
- Raycast 기반 피격 및 `EnemyBase` 데미지 연동
- 플레이어 체력과 사망 시 세션 종료 연동
- 조준선 UI와 인벤토리 오픈 시 입력 억제

### 상호작용과 루팅

- 반경 내 가장 가까운 `IInteractable` 탐색
- `F` 길게 누르기 방식의 아이템/상자 상호작용
- 주변 아이템 검색, 상자 컨테이너 열기, 루팅 UI 갱신
- 아이템 `ScriptableObject`에 이름, 아이콘, 가로/세로 크기, 무게, 가격 정의

### 인벤토리 UI

- 플레이어 인벤토리 8×6 논리 그리드
- 주변 루팅, 플레이어 보관함, 컨테이너 간 드래그 앤 드롭
- 다칸 아이템 배치와 잡은 위치 오프셋 처리
- 툴팁과 드래그 미리보기
- Unity 6 Input System용 `InputSystemUIInputModule` 런타임 설정
- 슬롯 아이콘·수량·오버레이가 포인터 입력을 가로채지 않도록 Raycast 정리
- 첫 슬롯 중앙 드래그를 막던 `BACKPACK` TMP 라벨의 Raycast 비활성화
- UI 생성기에서 새로 생성되는 텍스트도 기본적으로 Raycast 비활성화

### 적 AI와 세션

- 적 데이터 `ScriptableObject`: 체력, 속도, 시야/청각, 전투 수치, 팩션
- FSM 상태: Idle, Alert, Aggro, Retreat, Dead
- 시야각/거리/장애물 기반 감지와 사격 소음 반응 구조
- Maintainer 중립 경고 및 피격 시 적대 전환
- 적 사망 후 루팅 가능한 상자로 변환
- 처치, 획득 가치, 플레이 시간, 탈출 성공 여부를 기록하는 세션 결과 구조
- 세션 결과 UI 및 현재 씬 재시작 흐름

## 3. 씬 현황

| 씬 | 상태 | 용도 |
|---|---|---|
| `parkseongbin.unity` | 주 개발 씬 | 게임플레이, 지형, 오브젝트, 적, UI 통합 |

## 5. 알려진 주의점

- `CreateInventoryLootUI`의 테스트 씬 생성 경로에는 구형 `StandaloneInputModule` 생성 코드가 남아 있으나, 실제 인벤토리 초기화 시 이를 비활성화하고 `InputSystemUIInputModule`을 사용한다. 생성기 자체도 추후 완전히 신 Input System 방식으로 정리하는 것이 좋다.
- 씬과 프리팹의 직렬화 참조는 GUID에 의존한다. 에셋 이동은 Unity Editor에서 수행하는 것을 우선한다.
- UI 제목/장식 이미지/TMP 텍스트의 `Raycast Target`을 켜면 슬롯 드래그가 부분적으로 막힐 수 있다.
- 지형이나 정적 장애물을 바꾸면 NavMesh와 적 AI 동작이 달라질 수 있다.

## 6. 디자이너에게 권장하는 다음 작업 순서

1. `parkseongbin`을 복제해 레벨 디자인 작업본 생성
2. 플레이어 시작점, 전투 공간, 루팅 공간, 탈출 지점의 동선 블록아웃
3. 환경/프롭 3D 에셋을 카테고리별 폴더에 임포트하고 프리팹화
4. URP 머티리얼과 텍스처 압축/해상도 설정 정리
5. 콜라이더, Layer, Tag, Occlusion, LOD 설정
6. NavMesh 베이크 후 적 감지·추적·엄폐 동작 검증
7. 조명·포스트프로세싱·VFX·오디오 패스
8. 인벤토리/루팅/전투/탈출 전체 플레이스루 QA

## 7. 변경 시 필수 회귀 테스트

1. Unity Console에 컴파일 오류가 없는지 확인한다.
2. `parkseongbin` 씬에서 플레이어가 정상 스폰되는지 확인한다.
3. 이동, 조준, 발사, 재장전이 정상인지 확인한다.
4. 적이 플레이어를 감지하고 공격하며 사망하는지 확인한다.
5. 아이템과 상자에 `F` 길게 누르기로 상호작용되는지 확인한다.
6. `Tab`으로 인벤토리를 열고 주변/상자/가방 사이에서 드래그한다.
7. 첫 번째 인벤토리 슬롯의 위·가운데·아래 모든 지점에서 드래그 시작이 되는지 확인한다.
8. Missing Script, Missing Material, 분홍색 셰이더가 없는지 확인한다.
